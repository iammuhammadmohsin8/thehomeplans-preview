# Scroll process graph

Added immediately after the documented services section. The supplied circular-network reference is adapted into the Home Plans cream, forest green and muted gold brand. Four native button nodes surround the project: brief, scope, design/review, delivery. Scroll draws an outer path and connecting spokes; a corresponding explanation and original SVG document visual update alongside it. Reverse scrolling reverses the sequence. Nodes also provide direct navigation.

The workflow describes the remote services already shown on services.html. It introduces no guaranteed approval, delivery time, price, revision count or professional certification. Deliverables depend on the agreed service.

Buildless implementation: process-graph.css and process-graph.js. No new dependency, photo download or external runtime request. Uses native SVG, requestAnimationFrame, IntersectionObserver and ResizeObserver. It pauses rendering offscreen/hidden and presents static selectable steps for reduced motion. Native keyboard-accessible buttons and continue link are included. Rebuild through outputs/add_process_graph.py, called by create_direction_v2.py after services.
