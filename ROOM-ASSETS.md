# Scroll room hero assets

Four AI-generated concept frames of a consistent living room, created for The Home Plans. These are not photographs of a completed client project.

Sequence: empty ivory shell ? walnut panels and warm LED lighting ? ivory sofa, rug and coffee table ? framed abstract art.

Original PNG files are retained locally in ../room-sequence-originals/. WebP derivatives in assets/room-sequence/ use 768px for mobile and 1600px for desktop. Image content was generated/edited with ImageGen; Sharp only resized and compressed it.

Art direction: fixed eye-level tripod, 28mm lens, straight verticals, left garden glazing, oak flooring, ivory ceiling, walnut slat wall, understated photorealistic architectural editorial styling. For each edit, preserve exact camera, framing, windows, daylight and unaffected materials; selectively remove furnishing/art/panels to create earlier stages.

Animation: native sticky scroll with decoded local images and eased opacity blends. Reverse scrolling reverses the sequence. Stage buttons and skip link provide alternatives. Reduced motion uses static selectable stages. No external media requests or autoplay video.
