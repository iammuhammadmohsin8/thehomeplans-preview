# Online service regions

Full-width world map follows the process graph. The process footer and map entry share a scroll-revealed gold line. Three routes draw from an abstract online-studio hub below the map to the United States, Canada and Australia. This hub is outside geographic land and is not an office/location marker. Country selection updates the project prompt and route emphasis; CTA points to the existing enquiry section. No invented local office address, country landing page or client count.

Map source: Natural Earth, 1:110m admin countries, public-domain data. https://www.naturalearthdata.com/about/terms-of-use/
Downloaded GeoJSON: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson
Generated compact local SVG with an equirectangular overview; excludes Antarctica. Map is illustrative and not intended for navigation or boundary determinations.

Native SVG/CSS/requestAnimationFrame; no new npm dependencies or external runtime media. Rendering occurs on scroll while visible; reduced motion shows complete routes. Selectable country buttons work on mobile and keyboard. Country names remain available below the map on small screens.
