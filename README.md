# The Home Plans — client design preview

Public design prototype for client review before the WordPress implementation.

Pages: homepage, article template, guide library, Start Here and brand guide. All assets are local. No build or installation is required.

Sample editorial copy and illustrative drawings are marked as previews. Expert review, final content and WordPress implementation remain pending. The main domain is not connected to this repository.

The preview uses noindex metadata. This is a public site, not access-restricted content.

Deployment: GitHub Pages via GitHub Actions. If initial deployment reports that Pages is disabled, choose Settings → Pages → Source: GitHub Actions, then rerun the deployment workflow.
